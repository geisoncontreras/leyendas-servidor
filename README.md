# Servidor de Leyendas del Puño

Servidor del modo en línea del juego: salas con código, partida rápida, golpes por turnos y ranking de victorias.

- Iniciar: `npm install && npm start` (puerto `PORT`, por defecto 8080)
- Probar: `npm test`
- En Render: Web Service gratis, Build `npm install`, Start `npm start`.
